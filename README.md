# CapsLock IME Toggle

Windows 托盘工具：按下 CapsLock 切换当前窗口的中英文输入状态，同时避免改变大小写状态。

## 功能

- 支持微软拼音及常见第三方输入法。
- 仅拦截无修饰键的 CapsLock；按住 Ctrl、Shift、Alt 或 Win 时保留系统行为。
- 托盘菜单支持手动切换大小写、输入法设置和管理员模式重启。
- 支持单实例运行。
- 支持通过任务计划程序管理员权限自启动。

## 使用

运行 `capslock_ime_toggle.exe` 后，程序驻留在系统托盘。

右键托盘图标：

- **切换大小写**：放行一次 CapsLock，让系统切换大小写。
- **切换开机自启（管理员）**：创建或删除“登录时运行、最高权限”的计划任务。首次操作需要一次 UAC 授权。
- **输入法设置**：打开 Windows 输入法设置。
- **以管理员模式重启**：以管理员权限重新运行本程序。
- **退出**：关闭程序。

## 限制

- Raw Input 程序可以绕过普通键盘消息，自行处理 CapsLock；这是 Windows 输入机制限制，本程序无法阻止。
- 某些特殊输入法可能不支持通过当前方式切换中英文。
- 计划任务自启动仅在登录后运行，不负责系统启动阶段运行。

## 构建

需要 MinGW GCC、`windres` 和 GNU Make：

```text
make
```

生成文件：`capslock_ime_toggle.exe`
